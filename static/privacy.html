隐私说明

这是一个非官方玩家工具，仅用于记录扑克牌收藏进度。

游客模式

游客收藏只保存在当前浏览器的本地存储中，不会上传到服务器。清除浏览器数据会同时清除游客收藏。

注册后，服务会保存用户名、加盐后的密码摘要、登录会话和扑克牌收藏记录。不会收集姓名、手机号、邮箱或支付信息，密码不会以明文保存。

网站运行在 Cloudflare Workers 和 D1 上。Cloudflare 可能为安全、网络传输和防滥用目的处理 IP 地址及请求日志，具体规则以 Cloudflare 的隐私政策为准。

账号数据仅用于登录、跨设备同步和保障服务安全，不出售或用于广告画像。如需删除账号及收藏数据，请通过项目 GitHub 仓库联系维护者。
